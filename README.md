# 🛡 CyberBot — C# Console Cybersecurity Chatbot

![CI](https://github.com/<YOUR_USERNAME>/CyberBot/actions/workflows/ci.yml/badge.svg)

A structured, interactive console chatbot that greets users with ASCII art and a
voice chime, then answers common cybersecurity questions with a typing animation.

---

## Features

| Feature | Details |
|---|---|
| **ASCII banner** | Full-width CyberBot logo + shield art on startup |
| **Voice greeting** | Plays `assets/greeting.wav` (ascending C–E–G–C chime) |
| **Typing effect** | All bot responses appear character-by-character |
| **Cybersecurity Q&A** | Passwords, phishing, malware, VPN, 2FA, backups, daily tips |
| **Input validation** | Handles empty input, unknown queries, and EOF gracefully |
| **Clean architecture** | Logic split across `ChatBot`, `ResponseEngine`, `ConsoleUI`, `VoiceGreeting` |
| **CI pipeline** | GitHub Actions builds on Ubuntu, Windows, and macOS |

---

## Quick Start

### Prerequisites
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### 1 — Generate the greeting WAV (once)
```bash
python3 generate_greeting_wav.py
```

### 2 — Run
```bash
cd CyberBot
dotnet run
```

### 3 — Build Release binary
```bash
dotnet build -c Release
```

## Project Structure

```
CyberBot/
├── Program.cs                  ← Minimal entry point (≤ 10 lines)
├── CyberBot.csproj
├── assets/
│   └── greeting.wav            ← Generated by generate_greeting_wav.py
└── src/
    ├── ChatBot.cs              ← Session orchestrator (greet → chat → farewell)
    ├── ConsoleUI.cs            ← All rendering: banner, typing, colours, prompts
    ├── ResponseEngine.cs       ← Keyword → response lookup table
    └── VoiceGreeting.cs        ← Cross-platform WAV playback
.github/
└── workflows/
    └── ci.yml                  ← Build matrix: Ubuntu · Windows · macOS
generate_greeting_wav.py        ← Pure-Python WAV generator (no dependencies)
```

## CI / CD

The workflow in `.github/workflows/ci.yml` runs on every push and pull request:

1. Restores NuGet packages  
2. Builds in Release mode  
3. Publishes a self-contained binary  
4. Uploads build artefacts  

Targets: **ubuntu-latest**, **windows-latest**, **macos-latest**.

---

## Adding Your Own WAV

Replace `assets/greeting.wav` with any 16-bit PCM WAV file.  
On **Windows** it uses `System.Media.SoundPlayer`.  
On **macOS** it uses `afplay`.  
On **Linux** it tries `aplay` then `paplay`.
